Responsible productivity

Generative AI in my workflow

I treat AI as an assistant for thinking and productivity—not as a replacement for understanding the data or validating the answer.

Where Gen AI can help

  • Draft or debug SQL queries and explain query logic.
  • Suggest Excel formulas and troubleshoot formula errors.
  • Brainstorm data-cleaning strategies and validation checks.
  • Plan EDA questions, metrics, and edge cases.
  • Improve documentation, summarize findings, and structure reports.
  • Help explain technical results in clear business language.

My responsibility stays with me

AI-generated suggestions can be wrong, incomplete, or unsuitable for a dataset. I need to inspect the schema, test queries, verify calculations against the source data, check assumptions, and review dashboard outputs before trusting a result.

My aim is to use Generative AI to speed up repetitive work, learn unfamiliar concepts, compare approaches, and communicate more clearly—while keeping the analysis transparent and evidence-based.

This section describes an intended responsible workflow; it does not claim that AI was used for a particular task in each listed project.
