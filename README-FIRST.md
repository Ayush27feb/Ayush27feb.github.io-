# Ayush Kukreti — Data Analyst Portfolio

## Publish on GitHub Pages
1. Download and extract this ZIP on your computer.
2. Create a **public** GitHub repository named exactly `Ayush27feb.github.io` (GitHub username: `Ayush27feb`).
3. Upload the **contents** of this folder to the repository root. `index.html` must be at the root, not inside another nested folder.
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment choose **Deploy from a branch**, branch `main`, folder `/(root)`, and click **Save**.
6. Wait for the deployment, then open `https://Ayush27feb.github.io/`.

## Included
- Responsive dark navy/blue portfolio.
- About, skills, projects, expandable case studies, dashboard overview links, responsible Gen AI workflow, education, certificate, resume, and contact.
- Resume and certificate buttons use the exact Google Drive URLs provided by Ayush.
- Project repository links use the supplied URLs.
- No external libraries are required.

## Dashboard images
The dashboard gallery currently uses stylized placeholder artwork and clearly labels this in the website. It does **not** pretend these are actual Power BI screenshots. To show real dashboards:
1. Export screenshots from Power BI as PNG/JPG.
2. Place Finance images in `assets/dashboards/finance/`, Healthcare images in `assets/dashboards/healthcare/`, and HR images in `assets/dashboards/hr/`.
3. Then edit `index.html` to replace each mock dashboard art block with an `<img>` pointing to the screenshot, plus a caption. You can also send the screenshots to ChatGPT to update the site package for you.

## Before sharing
- Test all buttons and open the resume/certificate links in a private browser window.
- Confirm your resume/certificate Google Drive sharing is set to anyone with the link (viewer), if you want recruiters to open them.
- The PDF links in project cards assume the filenames supplied in your project descriptions:
  - Finance: `Finance_Dashboard_Overview.pdf`
  - Healthcare: `dashboard_view.pdf`
  - HR: `hrdahsboardview.pdf` (filename spelling as supplied; correct the URL if the actual filename differs).
  If a file link does not open, open that repository and copy the exact PDF file path from GitHub.
- Do not upload private data or confidential records to a public repository.

## Lifetime / backup note
GitHub Pages is free for public repositories, but no platform can guarantee lifetime availability. Keep this ZIP as an offline backup and periodically save a copy of your GitHub repository.
